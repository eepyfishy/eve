# Contributing

Thank you for your interest in eve.

This repository currently contains design documentation. Use [issues](https://github.com/eepyfishy/eve/issues) to report documentation problems or propose an assistant workflow. Keep proposals clear about what is planned and what has been demonstrated.

## Suggested contributions

- Point out ambiguous or unsupported feature claims.
- Suggest useful, testable assistant workflows.
- Help clarify the difference between eve, eef, and eefn.
- Propose improvements to permission and privacy language.
- Identify documentation gaps or accessibility problems.

## Before opening an issue

- Check whether your idea concerns eve's assistant behavior or eef's underlying networking/resource infrastructure.
- Describe the problem and expected behavior before proposing a complicated implementation.
- Do not submit personal data, credentials, or sensitive logs.
- Do not imply that speculative roadmap items are committed features.

Contributions are licensed under the [MIT License](LICENSE). Keep pull requests focused and explain which behavior or documentation they improve.
